# 📸 Instagram Clone (Django Practice Project)

A hands-on Instagram clone built with **Python** and **Django**, developed step-by-step from scratch to master backend architecture, custom user models, and core social interactions.

---

## 🚀 Features

- **Custom Authentication:** Built from the ground up using `AbstractBaseUser` and `BaseUserManager` (Username, Email, Phone Number).
- **Responsive Dark UI:** Minimalist, Instagram-inspired dark mode interface.
- **Feed & Posts:** Media upload, post creation, and responsive layout *(In Progress)*.
- **Social Graph:** User profile, interactions, and follow dynamics *(Upcoming)*.

---

## 🛠️ Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML5, CSS3, Django Template Language (DTL)
- **Database:** SQLite (Development)
